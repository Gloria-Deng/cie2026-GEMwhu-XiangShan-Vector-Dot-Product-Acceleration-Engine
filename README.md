# 香山向量点积加速引擎

本项目在香山昆明湖 V2 向量执行路径中实现自定义 `vdot.vv` 指令，对两个向量寄存器低 8 个有符号字节进行点积，结果写入目标寄存器低 32 位，其余位置清零。

团队：等一个棋迹；参赛单位：武汉大学集成电路学院；参赛队员：GEMwhu（陈思远）。赛题为“面向边缘AI大语言模型推理的RISC-V自定义vdot指令设计”。

- [项目演示视频](项目演示视频/)：包含三个阶段的视频。

## 指令与验证

指令针对 `e8`、`m1`、`vstart=0`、`vill=0` 和非掩码执行设计。它固定计算低 8 个字节，不根据 `vl` 截短。当前编码与 Zvqdotq 提案存在重叠，不能直接共用，具体请参阅[设计文档](技术文档/第二阶段_指令设计与功能验证.pdf)。

基础测试包含正数、负数、边界和随机输入，共 939 组。[整核波形分析](相关证明材料/results/vdot_full_core_20261102/README.md)记录了成功完成的超算任务 4127407：19 条目标指令的运算均为 2 周期，相关序列接收间隔 7 周期，独立序列接收间隔 1 周期。

## 性能结果

[点积测量](相关证明材料/experiments/throughput/measured_20261103/README.md)包含 348 次执行；16 项独立点积中，优化 RVV 和 vdot 分别为 4.001008 和 1.064012 周期/点积，周期比为 3.760303。依赖链中，较快的原 RVV 与 vdot 分别为 20.991935 和 7.008065 周期/点积，周期比为 2.995397。这些结果基于特定输入和计时方式，不能直接代表完整矩阵或大语言模型的加速。

[矩阵测量](相关证明材料/applications/gemm/measured_20261103/README.md)包含 72 次执行；六组比较均为标准 RVV 外积实现更快。当前矩阵实现未显示相对最佳标准 RVV 的端到端加速。
