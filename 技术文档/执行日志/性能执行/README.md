# 性能执行

本目录保存已完成的香山 DiffTest 性能任务输出和统计表：点积 348 次，矩阵 72 次。16 项独立点积在输入常驻寄存器的条件下，较快标准 RVV 与 vdot 的周期比为 3.760303；依赖链为 2.995397。六组矩阵比较均由标准 RVV 外积式获得最低周期。

逐次完整处理器输出和对应程序分别位于[点积测量](../../../相关证明材料/experiments/throughput/measured_20261103/README.md)及[矩阵测量](../../../相关证明材料/applications/gemm/measured_20261103/README.md)。
