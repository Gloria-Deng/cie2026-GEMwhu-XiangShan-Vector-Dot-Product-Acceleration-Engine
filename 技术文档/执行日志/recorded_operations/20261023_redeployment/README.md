# 20261023_redeployment

本目录保留 2026 年 10 月 23 日本地 WSL 环境的实际部署输出、工具版本、命令和终端画面。[local_checks](local_checks/README.md)为 2026 年 11 月 7 日本机重新执行的 12 项材料与程序检查，全部通过；各项输出中的绝对路径保留执行时的记录，本目录另有对应文件。

连续终端输出体现当次真实部署过程；`commands` 是实际执行的命令记录，不代表其中的机器路径在另一台机器上仍可直接使用。

| 文件或目录 | 用途 |
| --- | --- |
| [commands/](commands/) | 环境部署时执行的命令文件。 |
| [local_checks/](local_checks/) | 2026 年 11 月 7 日在本机执行的程序与材料检查结果。 |
| [continuous_terminal.txt](continuous_terminal.txt) | 环境部署过程中按实际顺序保存的终端原始输出。 |
| [final_terminal.png](final_terminal.png) | 环境部署结束时的终端画面。 |
| [installed_versions.txt](installed_versions.txt) | 部署时实际使用的工具版本。 |
| [operation_times.csv](operation_times.csv) | 环境部署操作的时间记录。 |
| [screen_capture_summary_part2.txt](screen_capture_summary_part2.txt) | 录屏片段的时间与内容概况。 |
| [screen_capture_times_part2.csv](screen_capture_times_part2.csv) | 录屏片段的时间信息。 |
| [terminal_readable.txt](terminal_readable.txt) | 同一次终端输出的便于阅读版本。 |
