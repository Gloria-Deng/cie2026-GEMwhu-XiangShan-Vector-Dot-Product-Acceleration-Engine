# commands

本目录保存实际环境部署时使用的命令。命令中的目录和系统设置属于当时执行环境，复现需根据实际环境调整。

| 文件或目录 | 用途 |
| --- | --- |
| [01_system_and_copy.sh](01_system_and_copy.sh) | 检查系统并准备部署文件的命令。 |
| [02_fixed_tools.sh](02_fixed_tools.sh) | 安装指定版本工具的命令。 |
| [02_recover_fixed_tools.sh](02_recover_fixed_tools.sh) | 准备指定版本工具安装文件的命令。 |
| [03_python_and_checks.sh](03_python_and_checks.sh) | 安装 Python 依赖并执行本地检查的命令。 |
| [begin_on_desktop.ps1](begin_on_desktop.ps1) | Windows 中启动并记录部署过程的命令。 |
| [download_assets_windows.py](download_assets_windows.py) | 在 Windows 中获取安装文件的程序。 |
| [session_environment.sh](session_environment.sh) | 部署会话使用的路径和环境设置。 |
| [start_session.sh](start_session.sh) | 启动连续终端记录的命令。 |
| README.md | 本目录的文件位置和用途说明。 |
