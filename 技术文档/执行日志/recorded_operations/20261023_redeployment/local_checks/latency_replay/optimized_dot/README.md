# optimized_dot

点积逐组拟合、不同实现的周期与周期比；比较范围和计时口径见 report.md。

| 文件或目录 | 用途 |
| --- | --- |
| [comparison.csv](comparison.csv) | 对应程序的性能比较表。 |
| [fits.csv](fits.csv) | 点积计时拟合结果。 |
| [optimized_speedup.csv](optimized_speedup.csv) | 优化 RVV 与 vdot 的周期比。 |
| [report.md](report.md) | 点积不同并行数量和实现的结果表。 |
| [speedup.csv](speedup.csv) | 点积测量计算得到的周期比。 |
| README.md | 本目录的文件位置和用途说明。 |
