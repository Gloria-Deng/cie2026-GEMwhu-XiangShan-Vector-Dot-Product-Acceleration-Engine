# 环境验证

本目录保存武汉大学计算节点上的 Linux、NEMU 和香山处理器环境验证输出，三层均通过。地址写入测试程序，表示实际执行节点的地址。

| 文件或目录 | 用途 |
| --- | --- |
| [emu.txt](emu.txt) | 启用 DiffTest 的香山处理器环境验证输出。 |
| [linux.txt](linux.txt) | 计算节点上的环境验证原始输出。 |
| [nemu.txt](nemu.txt) | 独立 NEMU 环境的环境验证输出。 |
| [status.txt](status.txt) | 三层环境验证的整体结果。 |
| README.md | 本目录的文件位置和用途说明。 |
