# vadd_original_wave

向量加法波形读取、逐元素结果和时序分析。

| 文件或目录 | 用途 |
| --- | --- |
| [check_result.json](check_result.json) | 波形内容、结果和时序检查。 |
| [cycle_calibration.csv](cycle_calibration.csv) | 波形时间与处理器周期的对应关系。 |
| [element_checks.csv](element_checks.csv) | 逐元素的计算结果检查。 |
| [extract_all.csv](extract_all.csv) | 从向量加法波形提取的信号变化。 |
| [fst_info.json](fst_info.json) | 波形文件基本信息。 |
| [vadd_all11_summary.csv](vadd_all11_summary.csv) | 向量加法 11 次执行的结果与时序。 |
| [vadd_exec1_events.csv](vadd_exec1_events.csv) | 向量加法首条执行的信号事件。 |
| [vadd_exec1_window.vcd](vadd_exec1_window.vcd) | 向量加法首条执行的局部波形。 |
| README.md | 本目录的文件位置和用途说明。 |
