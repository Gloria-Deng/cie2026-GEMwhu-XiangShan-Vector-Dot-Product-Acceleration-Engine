# recorded

本目录汇总正数、负数、边界及其他功能检查。功能程序和执行结果清单仅包含功能项目；构建信息保存实际构建时的内容，清单作用不同。

完整处理器执行输出及 NEMU 检查分别位于[处理器结果](../../../相关证明材料/results/cluster/20261019/README.md)和[NEMU 结果](../../../相关证明材料/results/recorded_nemu/README.md)。

| 文件或目录 | 用途 |
| --- | --- |
| [build_manifest.json](build_manifest.json) | 实际构建所用源码、处理器程序、参考库和工具信息。 |
| [functional_checks.csv](functional_checks.csv) | 三种实现的 939 组输入与完整寄存器结果检查。 |
| [program_manifest.json](program_manifest.json) | 保留的完整处理器功能程序清单。 |
| [summary.json](summary.json) | 完整处理器功能程序执行与向量加法波形结果汇总。 |
| [unit_latency_checks.csv](unit_latency_checks.csv) | 功能单元的各类输入、配置和时序检查结果。 |
| README.md | 本目录的文件位置和用途说明。 |
