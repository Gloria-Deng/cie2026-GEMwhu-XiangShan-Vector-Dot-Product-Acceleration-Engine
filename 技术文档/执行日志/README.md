# 执行记录

本目录保存赛题要求的环境部署和操作过程，并汇集当前功能、性能及波形的执行结果。

环境部署的终端原始输出见 [本地部署](本地部署/README.md)；三层环境验证见 [环境验证](环境验证/README.md)。完整处理器构建和最新整核录波见 [完整处理器构建与执行](完整处理器构建与执行/README.md)，点积及矩阵执行见 [性能执行](性能执行/README.md)。

赛题要求的完整源码、各次处理器输出、向量加法和 vdot 波形位于[相关证明材料](../../相关证明材料/README.md)。本目录为过程与结果入口，原始操作输出中的机器路径是执行当时的路径。
