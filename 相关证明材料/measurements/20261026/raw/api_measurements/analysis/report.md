# 通用矩阵接口实际周期

计时单位为8周期，读数是对应区间下界。compute在计时前整理B；pack_compute包括整理B。两者均包含接口检查、计算及写出C，计时边界的内存顺序控制也计入；不包含输入生成、逐元素结果检查、启动及结束等待。每项独立启动，不能将两种范围相减当成准确的数据整理成本。
