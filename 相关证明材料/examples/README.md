# examples

vdot 最小调用示例。

位置：`相关证明材料/examples/`。

下表列出本目录中的直接子项；子目录中的文件详见对应说明。

| 名称与相对位置 | 用途 |
| --- | --- |
| [minimal_vdot.bin](minimal_vdot.bin) | 同名程序的裸机二进制镜像 |
| [minimal_vdot.dis](minimal_vdot.dis) | 同名程序的反汇编文本，用于检查实际指令 |
| [minimal_vdot.elf](minimal_vdot.elf) | 同名程序的 ELF 可执行文件 |
| [minimal_vdot.S](minimal_vdot.S) | 汇编程序，用于vdot 最小调用示例 |
| [README.md](README.md) | 本目录文件位置与用途说明 |
