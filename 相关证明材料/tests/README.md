# tests

正数、负数、边界值和随机测试输入。

位置：`相关证明材料/tests/`。

下表列出本目录中的直接子项；子目录中的文件详见对应说明。

| 名称与相对位置 | 用途 |
| --- | --- |
| [gen/](gen/) | 生成的硬件和程序文件 |
| [cases_bound.labels.csv](cases_bound.labels.csv) | 边界值输入的编号与分类说明 |
| [cases_bound.txt](cases_bound.txt) | 边界值测试输入及参考结果 |
| [cases_neg.labels.csv](cases_neg.labels.csv) | 负数输入的编号与分类说明 |
| [cases_neg.txt](cases_neg.txt) | 负数测试输入及参考结果 |
| [cases_pos.labels.csv](cases_pos.labels.csv) | 正数输入的编号与分类说明 |
| [cases_pos.txt](cases_pos.txt) | 正数测试输入及参考结果 |
| [cases_rand.labels.csv](cases_rand.labels.csv) | 随机输入的编号与分类说明 |
| [cases_rand.txt](cases_rand.txt) | 该文件名所示测试程序的实际执行输出 |
| [cases_readable.csv](cases_readable.csv) | 向量运算测试输入及参考结果 |
| [cases_vadd.txt](cases_vadd.txt) | 向量加法测试输入及参考结果 |
| [README.md](README.md) | 本目录文件位置与用途说明 |
