# current_source_check

本目录功能的配套文件。

位置：`相关证明材料/results/current_validation/current_source_check/`。

下表列出本目录中的直接子项；子目录中的文件详见对应说明。

| 名称与相对位置 | 用途 |
| --- | --- |
| [expected/](expected/) | 应用随附接入修改后的源码，用于与已完成构建逐文件核对 |
| [pristine/](pristine/) | 应用接入修改前的上游源码文件，用于核对修改应用过程 |
| [apply_nemu.txt](apply_nemu.txt) | 本目录对应的执行输出、参数或检查结果：apply_nemu |
| [apply_xiangshan.txt](apply_xiangshan.txt) | 本目录对应的执行输出、参数或检查结果：apply_xiangshan |
| [build_manifest.json](build_manifest.json) | 超算构建使用的输入文件、源码和程序信息，供核对随附材料与已完成构建的一致性 |
| [checks.csv](checks.csv) | 本目录各项检查的完成状态及对应执行输出 |
| [README.md](README.md) | 本目录文件位置与用途说明 |
| [status.txt](status.txt) | 本目录对应检查或执行的完成状态 |
